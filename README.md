# AI Transaction Intelligence

## Live Demo

AI Transaction Intelligence is a Flask-based web application for analyzing transaction information and identifying unusual or potentially risky activity.

## Features

- Transaction amount detection
- Transaction classification
- Currency detection
- Transaction purpose identification
- Risk scoring
- Unusual activity detection
- Transaction history
- SQLite database storage
- Interactive dashboard
- Web-based interface
- Deployment with Render

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Git and GitHub
- Render

## Project Purpose

This project demonstrates practical skills in Python development, Flask application development, database integration, transaction analysis, dashboard design, and deployment.

## Running the Project Locally

Install the dependencies:

```bash
python -m pip install -r requirements.txt
python app.py
```
